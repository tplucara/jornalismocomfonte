Divulgação responsável

Se encontrar uma vulnerabilidade, envie para o endereço em /.well-known/security.txt antes de divulgar publicamente.

  • Descreva o impacto e os passos para reproduzir, sem explorar dados de terceiros.
  • Não peça ou publique conteúdo de usuários, documentos de verificação ou logs.
  • Respondemos pelo mesmo canal. Não oferecemos recompensa automática.

Não use scanners agressivos contra o serviço em produção. Este ambiente local é para desenvolvimento.
